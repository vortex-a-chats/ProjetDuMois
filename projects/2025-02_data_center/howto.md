# Centres de données

## Qu'est-ce qu'un centre de données ?

Un centre de données (datacenter) est une installation physique utilisée pour héberger des systèmes informatiques et des composants associés, tels que les systèmes de télécommunications et de stockage.

## Comment cartographier ?

### Tags principaux

- `telecom=data_center` : Tag principal pour identifier un centre de données

### Tags de qualité

- `name=*` : Nom du centre de données (obligatoire pour la qualité)

### Autres tags utiles

- `operator=*` : Nom de l'opérateur
- `operator:type=*` : Type d'opérateur (`commercial`, `government`, etc.)
- `building=*` : Type de bâtiment (`data_center`, `industrial`, etc.)
- `addr:*` : Adresse complète
- `website=*` : Site web
- `ref=*` : Référence ou code
