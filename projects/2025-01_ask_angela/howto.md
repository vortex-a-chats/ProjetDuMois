# Ask for Angela

Cartographions tous les établissements Ask for Angela pour améliorer la sécurité et l'accessibilité des lieux publics.

## Tags à utiliser

- `harassment_prevention=ask_angela` : Tag principal indiquant que l'établissement participe au programme Ask for Angela
- `name=*` : Nom de l'établissement
- `amenity=*` : Type d'établissement (bar, restaurant, café, etc.)
- `contact:phone=*` : Téléphone
- `contact:website=*` : Site web

Plus d'informations : https://wiki.openstreetmap.org/wiki/FR:Tag:harassment_prevention%3Dask_angela
