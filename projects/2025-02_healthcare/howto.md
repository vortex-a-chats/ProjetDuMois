# Lieux de santé

## Qu'est-ce qu'un lieu de santé ?

Un lieu de santé est un établissement ou un service lié à la santé et aux soins médicaux. Ce projet inclut les médecins, pharmacies, hôpitaux, cliniques, établissements sociaux et tous les lieux avec le tag `healthcare`.

## Comment cartographier ?

### Tags principaux

- `amenity=doctors` : Cabinet médical
- `amenity=pharmacy` : Pharmacie
- `amenity=hospital` : Hôpital
- `amenity=clinic` : Clinique
- `amenity=social_facility` : Établissement social
- `healthcare=*` : Tag générique pour les lieux de santé (peut être combiné avec d'autres tags)

### Tags de qualité

- `name=*` : Nom du lieu de santé (obligatoire pour la qualité)

### Autres tags utiles

- `operator=*` : Gestionnaire ou réseau
- `opening_hours=*` : Heures d'ouverture
- `phone=*` : Numéro de téléphone
- `website=*` : Site web
- `addr:*` : Adresse complète
- `healthcare:speciality=*` : Spécialité médicale
- `healthcare:service=*` : Services proposés
- `wheelchair=*` : Accessibilité en fauteuil roulant
