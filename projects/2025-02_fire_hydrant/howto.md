# Bornes incendie

## Qu'est-ce qu'une borne incendie ?

Une borne incendie (ou poteau d'incendie) est un point d'eau sous pression permettant aux pompiers de se ravitailler en eau lors d'interventions. Elles sont essentielles pour la sécurité incendie et doivent être facilement accessibles.

## Comment cartographier ?

### Tags principaux

- `emergency=fire_hydrant` : Tag principal pour identifier une borne incendie

### Tags de qualité

- `fire_hydrant:type=*` : Type de borne (obligatoire pour la qualité)
  - `pillar` : Poteau (borne aérienne)
  - `underground` : Souterraine
  - `wall` : Murale
  - `pipe` : Tuyau

### Autres tags utiles

- `ref=*` : Numéro de référence de la borne
- `fire_hydrant:diameter=*` : Diamètre de la canalisation (en mm)
- `fire_hydrant:pressure=*` : Pression de l'eau (en bar)
- `operator=*` : Gestionnaire (commune, syndicat des eaux, etc.)
- `colour=*` : Couleur de la borne
- `couplings=*` : Type de raccordement
