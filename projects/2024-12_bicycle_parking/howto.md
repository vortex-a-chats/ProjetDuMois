# Parkings vélo

Cartographions tous les parkings vélo pour encourager la mobilité douce.

## Tags à utiliser

- `amenity=bicycle_parking` : Tag principal
- `bicycle_parking=stands` : Arceaux
- `bicycle_parking=lockers` : Casiers
- `capacity=*` : Nombre de places
- `access=*` : Type d'accès

Plus d'informations : https://wiki.openstreetmap.org/wiki/FR:Tag:amenity%3Dbicycle_parking
