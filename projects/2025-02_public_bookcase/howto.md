# Microbibliothèques

## Qu'est-ce qu'une microbibliothèque ?

Une microbibliothèque (ou boîte à livres) est une petite bibliothèque de rue où les gens peuvent déposer et emprunter des livres gratuitement. Elles sont généralement installées dans des espaces publics et fonctionnent sur le principe du partage.

## Comment cartographier ?

### Tags principaux

- `amenity=public_bookcase` : Tag principal pour identifier une microbibliothèque

### Tags de qualité

- `access=*` : Conditions d'accès (obligatoire pour la qualité)
  - `yes` : Accès public
  - `private` : Accès privé
  - `permissive` : Accès avec permission

### Autres tags utiles

- `name=*` : Nom de la microbibliothèque si disponible
- `operator=*` : Gestionnaire (association, commune, particulier, etc.)
- `opening_hours=*` : Heures d'accès si applicable
- `shelter=*` : Si la boîte est protégée (`yes`/`no`)
- `wheelchair=*` : Accessibilité en fauteuil roulant
