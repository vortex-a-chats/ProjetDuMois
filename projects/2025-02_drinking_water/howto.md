# Fontaines à eau

## Qu'est-ce qu'une fontaine à eau ?

Une fontaine à eau est un point d'accès public à l'eau potable, généralement situé dans des espaces publics comme les parcs, les places, ou le long des rues. Elles permettent aux passants de se désaltérer gratuitement.

## Comment cartographier ?

### Tags principaux

- `amenity=drinking_water` : Tag principal pour identifier une fontaine à eau

### Tags de qualité

- `access=*` : Conditions d'accès (obligatoire pour la qualité)
  - `yes` : Accès public
  - `private` : Accès privé
  - `customers` : Réservé aux clients

### Autres tags utiles

- `name=*` : Nom de la fontaine si disponible
- `operator=*` : Gestionnaire (commune, entreprise, etc.)
- `bottle=*` : Possibilité de remplir une bouteille (`yes`/`no`)
- `seasonal=*` : Si la fontaine n'est disponible qu'en saison (`summer`, `winter`, etc.)
- `wheelchair=*` : Accessibilité en fauteuil roulant
