# Points d'eau potable

Cartographions tous les points d'eau potable pour améliorer l'accessibilité.

## Tags à utiliser

- `amenity=drinking_water` : Tag principal
- `drinking_water=fountain` : Fontaine
- `drinking_water=tap` : Robinet
- `access=*` : Type d'accès

Plus d'informations : https://wiki.openstreetmap.org/wiki/FR:Tag:amenity%3Ddrinking_water
