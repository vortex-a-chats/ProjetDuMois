# Lieux climatisés

## Qu'est-ce qu'un lieu climatisé ?

Un lieu climatisé est un espace (bâtiment, commerce, transport, etc.) équipé d'un système de climatisation permettant de maintenir une température agréable, particulièrement important lors des vagues de chaleur.

## Comment cartographier ?

### Tags principaux

- `air_conditioning=*` : Tag principal pour indiquer la présence de climatisation
  - `yes` : Climatisation complète
  - `no` : Pas de climatisation
  - `partial` : Climatisation partielle
  - `limited` : Climatisation limitée

### Tags de qualité

- `air_conditioning=*` : Présence et type de climatisation (obligatoire pour la qualité)

### Autres tags utiles

- `name=*` : Nom du lieu
- `opening_hours=*` : Heures d'ouverture
- `indoor=*` : Si c'est un espace intérieur (`yes`/`no`)
