# Parcs pour enfants

## Qu'est-ce qu'un parc pour enfants ?

Un parc pour enfants (ou aire de jeu) est un espace aménagé avec des équipements de jeu destinés aux enfants. Ces espaces sont essentiels pour le développement et le bien-être des enfants.

## Comment cartographier ?

### Tags principaux

- `leisure=playground` : Tag principal pour identifier un parc pour enfants

### Tags de qualité

- `access=*` : Conditions d'accès (obligatoire pour la qualité)
  - `yes` : Accès public
  - `private` : Accès privé
  - `permissive` : Accès avec permission

### Autres tags utiles

- `name=*` : Nom du parc si disponible
- `operator=*` : Gestionnaire (commune, association, etc.)
- `opening_hours=*` : Heures d'ouverture si applicable
- `fee=*` : Si l'accès est payant (`yes`/`no`)
- `min_age=*` : Âge minimum
- `max_age=*` : Âge maximum
- `surface=*` : Type de surface (`grass`, `sand`, `rubber`, etc.)
- `wheelchair=*` : Accessibilité en fauteuil roulant
