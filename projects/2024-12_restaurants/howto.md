# Restaurants

Cartographions tous les restaurants pour améliorer la qualité des données locales.

## Tags à utiliser

- `amenity=restaurant` : Tag principal
- `name=*` : Nom du restaurant
- `cuisine=*` : Type de cuisine
- `contact:phone=*` : Téléphone
- `contact:website=*` : Site web

Plus d'informations : https://wiki.openstreetmap.org/wiki/FR:Tag:amenity%3Drestaurant
